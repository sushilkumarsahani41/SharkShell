New in 2.0

MCP access for AI assistants

SharkShell ships a built-in MCP server. Point Claude Code (or any MCP client) at your instance and your AI assistant can list hosts, manage keys, and run commands, all with scoped access keys, fail-closed capabilities, and a full audit log.

connect your AI 
$ claude mcp add --transport http sharkshell \
    https://your-host/api/mcp \
    --header "Authorization: Bearer sk-your-access-key"
New in 2.0

Multi-user organizations

Admins create accounts with temp passwords, manage roles, deactivate members, and reset credentials. Every resource stays private to its owner until shared.

New in 2.0

TOTP two-factor auth

Per-user 2FA with any authenticator app, 10 single-use recovery codes, lockout protection, and admin reset for lost devices.

New in 2.0

Scrollback restore

Reload the page, drop your connection, come back later. Your terminal history is repainted exactly where you left it, VS Code-style.

Encrypted keystore

Generate, upload, and organize ED25519, ECDSA, and RSA keys. Everything is AES-256-GCM encrypted at rest.

Multi-tab terminals & workspaces

Tabbed SSH sessions organized into named workspaces. Sessions persist through refreshes — click to reconnect.

Host & key groups

Color-coded groups for staging, prod, and everything in between. Connect an entire group at once.

~/security ▊

Security is the product

An SSH manager holds your most sensitive credentials. We treat it that way.

✓

AES-256-GCM at rest

Every password, private key, and TOTP secret is encrypted before it touches the database.

✓

TOTP 2FA with recovery codes

Two-step login, hashed single-use recovery codes, and 5-failure lockout.

✓

RS256 JWT auth

Auto-generated 2048-bit RSA keypair for token signing. No shared-secret shortcuts.

✓

Scoped MCP keys + audit log

AI access keys are capability-scoped and fail closed. Every MCP action is logged.

✓

First-run lockdown

Registration closes automatically after the first admin account is created.

✓

Non-root container

Runs unprivileged; secrets live in persistent volumes and survive restarts.

~/quickstart ▊

Deploy in 60 seconds

One command. Secure defaults are auto-generated.

1

Recommended: Docker Compose

Download the compose file, run the init script, and start.

terminal 
# Download
curl -sO https://raw.githubusercontent.com/sushilkumarsahani41/SharkShell/main/docker-compose.prod.yml
curl -sO https://raw.githubusercontent.com/sushilkumarsahani41/SharkShell/main/init.sh
chmod +x init.sh

# Setup & Run
./init.sh
docker compose -f docker-compose.prod.yml up -d
2

Or: Docker run with your own PostgreSQL

Point the standalone container at an external database.

terminal 
docker run -d -p 8080:80 \
  -e DB_HOST=your-db-host \
  -e DB_USER=your-user \
  -e DB_PASSWORD=your-password \
  -e DB_NAME=sharkshell \
  -v sharkshell-secrets:/app/secrets \
  greatsharktech/sharkshell:latest
3

Open & create your admin

Visit http://localhost:8080. The first account becomes the org admin, then registration locks itself.
